
# DogBreed Quiz App

## About the App
Users can guess different dog breeds by looking  at pictures and selecting the correct answers.

## Features
- Displays 3 dog breed questions.
- Shows a dog picture for each question.
- Uses dropdown menus to select answers.
- Submit button to check answers.
- Calculates the score out of 3.
- Displays a Toast message with the result.
- Uses ScrollView to scroll through questions.
- Uses fontawesome6 for the icon

## Dog Breeds
1.  Husky
2. Golden Retriever
3. Pomeranian
